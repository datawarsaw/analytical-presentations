# Analytical presentation review gates

Use for final QA and to diagnose existing decks before a substantial rewrite. A review must distinguish verified PASS, partial review and unverified items.

## Gate 1 - Executive decision and narrative

- [ ] Executive Summary is the **first substantive slide** after any approved cover, and states the real conclusions plus defensible recommended actions or decision/validation needed.
- [ ] Summary reflects the actual evidence, not what was expected at the start of analysis.
- [ ] Action titles are defensible, not empty labels; each slide has one primary insight.
- [ ] Ghost-deck test: titles alone tell the argument, without duplicated, conflicting or orphan messages.
- [ ] The deck communicates business implications and decisions; it is not merely a dashboard walkthrough.
- [ ] Recommendations are explicit, prioritized where meaningful, and bounded by evidence and uncertainty; not fabricated.

## Gate 2 - Claim, evidence and comparison

- [ ] Every important claim is supported by its displayed exhibit or an accessible cited source.
- [ ] Comparisons are like-for-like; period, base, cohorts, population, metric definition and currency are aligned.
- [ ] % vs percentage points, variance directions, units, totals, rounding and targets reconcile.
- [ ] Claims such as growth, underperformance, causation and ROI are appropriately qualified.
- [ ] No metric is judged as "good" or "bad" without a stated standard and direction of desirability.
- [ ] Exhibits avoid distorted axes, mismatched scales, hidden exclusions, missing denominators or non-additive waterfalls.

## Gate 3 - Commentary and information placement

- [ ] Comments on the main slide explain implication, cause hypothesis, risk, next action or uncertainty; **do not echo the chart**.
- [ ] Slide body is scannable for executives; extended analysis is in notes/appendix or appropriately linked source data.
- [ ] All data-slide footers contain verified source/period/scope and the relevant filters and exclusions. Metadata are not invented.
- [ ] Footers do not contain commentary, conclusions or detailed methodology.
- [ ] Speaker notes remain readable, accurate and preserved after edits.
- [ ] Any caveat important enough to alter the headline is visible on the main slide, not buried in the appendix.

## Gate 4 - Visual and brand quality

- [ ] Approved master/template, typefaces, colors, logo, slide size and section conventions are preserved.
- [ ] Every edited slide is rendered and visually reviewed at suitable size, not only text-extracted.
- [ ] No cropping/overflow, collision, clipped labels, undersized legends or footer overlap.
- [ ] Chart color and scenario semantics stay consistent; key comparison is visually obvious without relying on color alone.
- [ ] Native elements remain editable when the source and engine permit it; all referenced images/charts remain correctly linked.

## Gate 5 - File safety and delivery

- [ ] The correct presentation was activated/edited and only user-authorized content was changed.
- [ ] Original file protected when needed; save location and file integrity validated by the technical PPTX workflow.
- [ ] Final Executive Summary refreshed; slide titles and detailed content have no contradictions.
- [ ] Deliverable includes exact file/link, changed slide list, QA outcome, outstanding assumptions or missing source metadata.

## Rubric for audits

Use `PASS / NEEDS FIX / UNVERIFIED` per gate. Give up to three high-impact fixes before low-level polish. Never report "QA passed" for a deck that was not rendered, or "data verified" when only a screenshot was available.

### Reviewer response template

- **Decision quality:** PASS / NEEDS FIX / UNVERIFIED (short reason).
- **Story:** PASS / NEEDS FIX / UNVERIFIED (ghost deck / weak action titles).
- **Evidence:** PASS / NEEDS FIX / UNVERIFIED (notable baseline/definition risks).
- **Visuals:** PASS / NEEDS FIX / UNVERIFIED (rendered slides and issues).
- **Top 3 recommended corrections:** specific slide(s) and proposed changes.
- **Protected inputs:** sources, original file, approved brand rules, limitations.
