# Evidence, comparison and visual integrity

Load before designing performance KPI slides, interpreting trend/variance, checking factual claims or building the Executive Summary.

## Every performance KPI needs an evaluation frame

For each substantive metric, establish at least one meaningful comparator **when available and genuinely comparable**:

- LY / YoY: same business season, date range, channel, market, cohort and metric definition. Note leap-year, weeks, currency and base changes when material.
- Previous period: a useful momentum signal, but control for seasonality before calling it a success/failure.
- Target / plan / forecast: show target definition and date; do not treat it as an independent market benchmark.
- Peer / market benchmark: verify composition, currency, coverage, method and benchmark date.
- Control / cohort / segment: ensure denominators and eligibility rules match; distinguish correlation from a causal experiment.
- Business threshold: explicitly define the success criterion; avoid invented red/yellow/green cutoffs.

A metric without a valid comparator may still be included when material. Label the comparison limitation; never synthesize a fictitious benchmark. If a claim says "strong", "weak", "high", "low", "improved" or "underperformed", verify the referenced standard.

## Comparison checks

Before accepting a takeaway, audit:

- **Period**: exact dates, FY definition, YTD alignment, MTD cutoffs, refresh timestamp, comparable time windows.
- **Population**: included stores/markets/channels, active/inactive population, sample size, cohorts, inclusion/exclusion criteria, underlying grain.
- **Definition**: event vs unique customer, gross vs net, tax included/excluded, returns/refunds, shipped vs booked, actual vs estimate, currency and FX method.
- **Math**: percentage change vs percentage-point difference; numerator, denominator, zeros/negative baselines, signed variance, totals, rounding and percent-of-total.
- **Desirability**: an increase is favorable only if higher is objectively better for that metric and context (e.g. churn increase is unfavorable; risk-adjusted contribution may differ from revenue growth).
- **Attribution**: avoid causal language for observational contrasts; consider mix, coverage, confounding, small samples or one-off events.
- **Visibility**: label units, period, comparator and variance on the exhibit so the viewer need not decode a long legend.

If any change of definition or insufficient comparability compromises a headline, revise the claim or visibly flag the limitation.

## Exhibit choices

| Question to answer | Prefer | Avoid |
| --- | --- | --- |
| How has performance changed over time? | Line or column with same-period comparator / target | 3D effects and unexplained dual axes |
| Which categories drive the result? | Ranked bars, contribution bridge where appropriate | Unsorted legend-dependent bars |
| How did actual compare with plan/LY? | Paired bars, variance chart, delta labels | Showing only actual without baseline |
| Where did movement originate? | Driver decomposition/bridge with reconciled totals | Suggesting additive causation from non-additive categories |
| What is the mix? | 100% stacked bars, small multiples, or clear table | Many-slice pies requiring precise comparison |
| What value must leadership decide on? | Single highlighted KPI + baseline/target + relevant context | Isolated big number with no evaluative frame |
| Do exact numbers or definitions matter? | Compact table with highlighted variance and source | Overplotted chart with unreadable labels |

One slide can include two or more aligned exhibits when necessary to substantiate a **single** insight (e.g. an absolute-value trend plus a normalized share trend). Keep shared scales and labels consistent. If views imply different messages, split the slide.

## Chart semantics and perception

- Keep chart types, series colors, ordering and time axes consistent across a deck. The same color means the same category or scenario, unless an approved client profile specifies a different semantic system.
- Use direct labels where they speed comprehension. Make the comparison or critical variance visually prominent; reduce decorative elements and unnecessary gridlines.
- For bar/column charts, baseline normally starts at zero. If an exception is analytically necessary, use an obvious axis break and disclose it; do not disguise exaggeration.
- For paired/comparable plots, use the same scale, unit and axis boundaries unless explicitly explained. Do not compare unlike axes as if directly comparable.
- Label a negative number, unfavorable variance or uncertainty unambiguously. Color alone must not communicate favorability.
- No source or sample size? Do not present a point estimate as a robust fact.

## Interpretive honesty

Separate four levels of statement:

1. **Observed**: directly supported descriptive facts.
2. **Hypothesized**: a plausible cause or interpretation requiring validation.
3. **Forecast**: an estimate under explicit assumptions.
4. **Recommended**: a proposed action supported by observed evidence and a proportionate risk/benefit judgment.

Never silently escalate (1) to (2) or (2) to (4). A recommendation may call for investigation instead of immediate operational intervention.
