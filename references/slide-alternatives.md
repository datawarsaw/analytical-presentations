# Slide alternatives: reimagine without changing the evidence

Load only when the user requests alternative designs, a stronger visual explanation, or a substantive redesign of an existing analytical slide. This supplements, rather than replaces, the story, evidence, brand, and PowerPoint workflow references.

## Lock the source slide before redesigning

1. Identify the exact deck and slide; inspect visible text, charts and their underlying data (where accessible), tables, speaker notes, footer, masters/layouts, and any manual annotations.
2. Record the source slide's **single primary claim**, metrics, units, denominators, comparison baseline, reporting period, filters, exclusions, and source lineage. Separate verified figures from estimates and hypotheses.
3. Preserve source numbers and definitions across alternatives. Recompute only transparent, authorized derivatives from the same verified inputs; never add an unsupported segment, driver, comparison, benchmark, or causal explanation merely to fill a design.
4. Respect the approved client template and any exact corporate slide layout. Treat a screenshot as visual reference, not as a substitute for editable native chart data.

## Generate up to three genuinely different alternatives

Use three distinct *information structures*, when the evidence supports them:

- **A — Comparison-led:** foreground the decision-relevant contrast (e.g. period vs prior period, actual vs plan, comparable cohorts); use an aligned side-by-side or delta exhibit where appropriate.
- **B — Driver/segment-led:** show verified distribution, contributions, or segments *only when the supplied source includes them*. A correlation or composition does not prove causality. If drivers are unavailable, propose a diagnostic structure instead of inventing one.
- **C — Decision-led:** organize evidence around a concrete implication, option, risk, or validation decision; separate observed outcomes from proposed action and its uncertainty.

Do not force three variants if the evidence sustains only one or two. Color-only, crop-only, and typography-only treatments are not substantively different alternatives. Each concept must pass the action-title, one-insight, claim-to-exhibit, and like-for-like-comparison checks.

## Return a decision-ready comparison before modification

For each defensible option, give: proposed action title; the exhibit or layout; one sentence on why it strengthens the argument; caveat/assumption; and implementation or editability constraints. Recommend the best option against **evidence fit, readability, narrative role, native-editability, brand fidelity, and scope safety**. Mark any unverified requirement explicitly.

- In review/ideation mode, do not mutate the presentation.
- When asked to create multiple slide versions, work on separate duplicates or a clearly named copy. Preserve the original and existing notes/footers; avoid overwriting a master or moving other slides.
- If the user has already authorized implementation of a preferred variant, implement only that variant on a safe copy and render/re-read it. If no choice was made, present the alternatives and recommendation rather than silently selecting one for destructive in-place editing.
- Prefer native/editable charts and text; never convert an existing editable chart into a screenshot without explicit consent. When a particular redesign cannot preserve editability, say so and provide an editable alternative.

## QA for each implemented option

Verify the exact numbers, denominator and baseline, action title, narrative continuity, notes, scope footer, original chart editability, master/template fidelity, and visual overflow. Inspect rendered output; do not claim a variant is delivered or visually verified based only on a text storyboard.

**Miniature synthetic example:** Given *only* total sales 110 vs prior 100, a comparison-led delta (+10%, if the definitions and bases match) is defensible. A driver-led claim such as "online drove growth" is **not** defensible without channel data.
